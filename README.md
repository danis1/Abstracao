# Abstração - Orientação a Objetos em Java

> 🎓 **Trabalho Acadêmico**  
> Projeto desenvolvido para a disciplina de **Técnicas de Programação I** do curso de **Desenvolvimento de Software Multiplataforma (DSM)** na **FATEC Praia Grande**.

---


## Lista de Exercícios de Abstração

| Exercício | Conceito Abordado | Foco da Abstração |
| :--- | :--- | :--- |
| 🚘 **AplicativoDeVeiculos** | Modelagem de Veículo | Métodos de consumo, aceleração e autonomia. |
| 🏦 **BancoDigital** | Entidade Conta Bancária | Operações de saldo, depósito e saque. |
| ⚡ **ContaDeEnergia** | Consumo Elétrico | Cálculo de tarifas por faixas de consumo. |
| 📦 **ControleDeEstoque** | Entidade Produto | Gerenciamento de entradas e saídas de itens. |
| 🌡️ **ConversorDeTemperatura** | Utilitário de Conversão | Métodos de transformação entre escalas térmicas. |
| ⚖️ **IMC** | Cálculo de Saúde | Abstração de pessoa e cálculo do índice corporal. |
| ✈️ **PlanejamentoViagem** | Logística e Custos | Modelagem de rotas, combustível e hospedagem. |
| 👔 **RH** | Gestão de Colaboradores | Classes de funcionários, cargos e folha salarial. |
| 🛒 **SistemaDeVenda** | Vendas & Pedidos | Relação entre itens, pedidos e totalizadores. |
| 🎓 **SistemaEscolar** | Entidade Aluno/Turma | Métodos para notas, frequências e médias. |
| 🏪 **SistemaMercearia** | Caixa e Estoque | Controle de vendas rápidas e produtos de mercado. |
